# ThinkDivisionV Statics

ThinkDivisionV is a growing collection of **interactive Statics tools, practice resources, and engineering explanations** built to help students understand the reasoning behind common mechanics problems.

## Live Site

https://daveakadave-p1.github.io/Statics/

## Current Tools

### 2D Support-Reaction Solver
- Simply supported beam with a pin at A and roller at B
- Multiple vertical point loads
- Optional uniform distributed load
- Optional applied couple
- Solves for `Ax`, `Ay`, and `By`
- Shows a free-body-diagram preview and equilibrium equations

### Vector Tools
Available at:

https://daveakadave-p1.github.io/Statics/vector-tools.html

Current vector topics include:
- Adding vectors
- Resultant force
- Magnitude of a force
- Dot product
- Angle between vectors
- Force components from magnitude and direction

### Quick Calculators
- Moment magnitude
- 2D force resultant

## Project Goal

The goal is to build ThinkDivisionV into a practical engineering-learning hub that connects YouTube explanations with interactive tools students can use to **check their work without skipping the reasoning**.

Planned areas include:
- Original practice problems
- Step-by-step worked examples
- Video links organized by topic
- Truss tools
- Centroid tools
- Friction tools
- Additional equilibrium tools

## Design Philosophy

The tools are intended to support learning rather than replace it. Students should still draw diagrams, define sign conventions, write equilibrium equations, and verify assumptions independently.

## About ThinkDivisionV

ThinkDivisionV is an engineering-education project focused first on Statics, with room to expand into other mechanical-engineering topics over time.

## Disclaimer

These tools are for educational use. Always verify units, signs, assumptions, and final answers independently.
